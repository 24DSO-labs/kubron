# ADR-0004: Сессии: cookie + CSRF + Origin

- Статус: предложено (ждёт утверждения тимлидом)
- Дата: 2026-10-25
- Связано: Задача 1.4

## Контекст

В вебе нужна идентификация пользователя без хранения токена в JS.

## Решение

Cookie `HttpOnly; Secure; SameSite=Lax`, CSRF-токен, проверка `Origin`. Сессия хранит userID, lastActive, активный кластер. В десктопе — одна неявная сессия.

## Рассмотренные альтернативы

Токены в `localStorage` (уязвимы к XSS); JWT без серверного состояния (нельзя отозвать).

## Последствия

Сессии лежат в БД (для HA, см. ADR-0007). Автовыход по `ReportActivity`.
