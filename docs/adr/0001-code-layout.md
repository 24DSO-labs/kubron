# ADR-0001: Структура кода: ядро в internal/app, две оболочки

- Статус: предложено (ждёт утверждения тимлидом)
- Дата: 2026-10-25
- Связано: Задачи 0.2, 0.4

## Контекст

`App` (около 150 методов) лежит в `package main`. Второй `main` (HTTP-сервер) не может его импортировать, а копирование кода сделало бы два кодовых базиса.

## Решение

Перенести `app*.go` в `internal/app`. `main.go` остаётся оболочкой Wails; новый `cmd/kubron-server` — оболочкой HTTP. Имена методов не меняются, поэтому биндинги `wailsjs` остаются прежними.

## Рассмотренные альтернативы

Копировать код (расхождение версий); держать сервер внутри `package main` под build tag (не масштабируется).

## Последствия

Нужно обновить путь в `internal/auth/policy_test.go` (glob `../../app*.go`) и CI.
