# ADR-0011: SSO: стандартный OIDC за интерфейсом Authenticator

- Статус: предложено (ждёт утверждения тимлидом)
- Дата: 2026-10-25
- Связано: Задача 0.10, этап 6

## Контекст

SSO нужен только для входа в Kubron; IdP один на установку; провайдер заранее неизвестен.

## Решение

Authorization code + PKCE через `coreos/go-oidc`; issuer, client-id, claims — в конфиге. Интерфейс `Authenticator`: локальный вход в ядре, OIDC — в платном модуле. Реализация в этапе 6, точка расширения закладывается сейчас.

## Рассмотренные альтернативы

Жёстко прописать Keycloak; SAML (вне плана).

## Последствия

Интерфейс нужно стабилизировать до этапа 6 (см. ADR-0013, задача 0.10).
