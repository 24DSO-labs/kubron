# ADR-0005: Менеджер кластеров: общий пул + сессионный вид

- Статус: предложено (ждёт утверждения тимлидом)
- Дата: 2026-10-25
- Связано: Задачи этапа 2 (2.1–2.x); спайк-прототип до начала

## Контекст

`Manager` хранит один `activeCtx`; `activateLocked` закрывает остальные кластеры; 136 методов зависят от `GetActiveConnection`.

## Решение

Общий пул подключений (informers с refcount и TTL) и `ForSession(s)` — поверхностная копия `Manager` с собственным `activeCtx`, терминалами, логами и port-forward, делящая пул.

## Рассмотренные альтернативы

Переписать 136 методов на явный ctx кластера (дорого, риск регрессий); отдельный `Manager` на сессию (нагрузка на kube-apiserver растёт кратно).

## Последствия

Нужны `singleflight`/кэш для защиты apiserver, лимит стримов на пользователя вместо глобального `logMaxStreams = 50`, владение ресурсами сессией. Выход из сессии не должен останавливать чужое.
