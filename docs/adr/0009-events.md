# ADR-0009: Адресные события; серверные ID

- Статус: предложено (ждёт утверждения тимлидом)
- Дата: 2026-10-25
- Связано: Задачи 1.5, 1.6

## Контекст

`EventsEmit` рассылает всем, а ID терминала приходит от клиента — возможен доступ к чужому.

## Решение

Event hub с адресацией: по сессии, по кластеру, по владельцу ресурса. ID терминалов и логов генерирует сервер и проверяет владельца.

## Рассмотренные альтернативы

Фильтрация на клиенте (небезопасно).

## Последствия

Меняется сигнатура Emit; тесты на «доходит только владельцу».
