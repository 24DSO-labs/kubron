# ADR-0014: Локализация интерфейса

- Статус: предложено (ждёт утверждения тимлидом)
- Дата: 2026-10-28
- Связано: ADR-0010 (слой platform/), docs/i18n.md

## Контекст

Интерфейс был смесью русских и английских текстов; бэкенд возвращал русские ошибки. Нужно
несколько языков (английский и русский сразу, остальные позже) и простой путь добавить язык.

## Решение

- `vue-i18n` v11, только Composition API (`legacy: false`). Выбран язык и сохраняется в
  `localStorage`; по умолчанию — язык системы, иначе английский.
- **Приложение «говорит» по-английски**: английский — базовый язык и fallback, остальные — переводы
  с него. Бэкенд отдаёт только английский текст и язык не знает.
- Перевод ошибок бэкенда — на фронтенде по шаблонам сообщений (`locales/*/backend.json`);
  неизвестные сообщения показываются как есть.
- Сообщения — JSON в `src/i18n/locales/<язык>/<раздел>.json`; английский вшит в бандл, остальные
  языки подгружаются чанками. Новый язык = копия каталога `en` + запись в `languages.ts`.
- Данные-описания (колонки, меню, свойства) хранят ключи сообщений; рисующий код вызывает `tl()`.
- Даты и числа форматируются по языку интерфейса (`Intl`), а не по системным настройкам.
- Проверки без зависимостей (`scripts/i18n-check.mjs`): полнота ключей, плейсхолдеры, ссылки в коде,
  кириллица вне комментариев, тест соответствия Go-ошибок таблице перевода.

## Рассмотренные альтернативы

- Бэкенд знает язык и переводит сам: ломает единый источник текстов, усложняет веб-режим (ADR-0003).
- Коды ошибок вместо текстов: хорошее долгосрочное решение, но требует переписать все
  `errors.New` и обработку ошибок; текущая схема совместима и позволяет мигрировать по частям.
- `@intlify/unplugin-vue-i18n`: precompile и `<i18n>`-блоки не нужны при JSON-файлах; лишняя зависимость.

## Последствия

- Любой новый пользовательский текст — ключ в `locales/en` и во всех остальных языках, иначе CI красный.
- Новая Go-ошибка требует записи в `backend.json`.
- Сохранённые настройки ширины колонок списков ресурсов сбросятся один раз (ключ больше не зависит
  от переводимого заголовка).
