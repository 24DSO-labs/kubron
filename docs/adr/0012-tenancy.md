# ADR-0012: Мультитенантность: организация → команда → кластер

- Статус: предложено (ждёт утверждения тимлидом)
- Дата: 2026-10-25
- Связано: Этап 3, раздел 6

## Контекст

DevOps разных команд одной организации должны видеть только свои кластеры.

## Решение

Сущности «организация → команда → кластер»; роли назначаются на команду; один кластер — одна команда (без `ClusterGrant`).

## Рассмотренные альтернативы

Гранты на кластер для произвольных субъектов (сложнее, не нужно по требованиям).

## Последствия

Перенос кластера между командами — отдельная админ-операция.
