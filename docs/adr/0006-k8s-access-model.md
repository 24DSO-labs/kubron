# ADR-0006: Модель доступа к Kubernetes

- Статус: предложено (ждёт утверждения тимлидом)
- Дата: 2026-10-25
- Связано: Раздел 7 плана, этап 3 (3.7)

## Контекст

Сервер подключается к кластерам от имени одной учётной записи; люди различаются только в Kubron.

## Решение

Подключение по конфигу: kubeconfig (токен/сертификат), ServiceAccount, in-cluster или нативный `oidc-password`. `exec` запрещён в веб-режиме (RCE, нет TTY). Права людей — app-RBAC; проброс личной идентичности в Kubernetes вне плана. Один кластер принадлежит одной команде.

## Рассмотренные альтернативы

Impersonation/проброс токена пользователя (требует изменений в кластере); `exec`-плагины на сервере (риск RCE).

## Последствия

Сервер = права этой учётной записи для всей команды; снижается ролями приложения и отдельной учётной записью с минимальными правами (рекомендация). Аудит по людям ведёт только Kubron.
