# ADR-0013: Лицензия: Apache-2.0 ядро + платный модуль

- Статус: предложено (ждёт утверждения тимлидом)
- Дата: 2026-10-25
- Связано: Задачи 0.9, 0.10

## Контекст

Проект open source; платные функции по подписке позже, сейчас — только SSO/OIDC.

## Решение

Ядро — Apache-2.0. Платные функции — отдельный модуль в приватном репозитории (образ `kubron-ee`) с коммерческой лицензией, подпись лицензионного ключа Ed25519, проверка без сети, срок действия и льготный период. Локальные пользователи, роли, аудит и аварийный админ остаются в ядре. Подключение через публичные интерфейсы (`pkg/ext`) или build tags. DCO для внешних вкладов; README честно объясняет, что SSO платный.

## Рассмотренные альтернативы

AGPL-3.0 + CLA (отпугивает компании); source-available (не open source).

## Последствия

Риск облачного форка ядра; перед публичным релизом показать лицензию и ключ юристу; проверить название/торговую марку.
