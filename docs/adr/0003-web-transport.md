# ADR-0003: Транспорт веба: универсальный RPC + WebSocket

- Статус: предложено (ждёт утверждения тимлидом)
- Дата: 2026-10-25
- Связано: Задачи 1.2, 1.5, 1.6

## Контекст

Фронтенд ходит через `callApp(name, ...args)` и сгенерированные биндинги; REST на 150 методов дорог и дублирует контракт.

## Решение

`POST /api/rpc/{method}` с JSON-массивом аргументов, диспетчер на рефлексии с allowlist; события и терминал — WebSocket (`/api/ws`, binary WS для терминала).

## Рассмотренные альтернативы

150 REST-ручек; gRPC-web (лишняя инфраструктура и генерация).

## Последствия

Нужен контрактный тест: каждый экспортируемый метод в allowlist либо в списке запрещённых. Лимиты тела и отмена по `ctx`.
