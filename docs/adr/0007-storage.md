# ADR-0007: Хранилище: интерфейс Store, файлы и PostgreSQL

- Статус: предложено (ждёт утверждения тимлидом)
- Дата: 2026-10-25
- Связано: Задача 0.8, этап 3

## Контекст

Файлы `users.json` и `audit.log` рассчитаны на один процесс; нужны 2+ реплики.

## Решение

Интерфейс `Store` с реализациями: файловая (десктоп) и PostgreSQL (сервер). SQLite — только local-режим. PostgreSQL внешний, ставит пользователь. Миграции под `pg_advisory_lock`, кросс-репличные события через `LISTEN/NOTIFY`.

## Рассмотренные альтернативы

Только SQLite (нет HA); общий том с файлами (гонки и блокировки).

## Последствия

Появляется внешняя зависимость сервера; `/readyz` проверяет БД.
