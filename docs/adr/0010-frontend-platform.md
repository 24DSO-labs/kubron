# ADR-0010: Фронтенд: слой platform/ и сборка по цели

- Статус: предложено (ждёт утверждения тимлидом)
- Дата: 2026-10-25
- Связано: Задачи 0.5–0.7, 1.7

## Контекст

16 файлов импортируют `wailsjs/go/main/App` напрямую, 7 — `wailsjs/runtime`.

## Решение

Слой `platform/` (`api.ts`, `events.ts`, `files.ts`); реализация выбирается при сборке `VITE_TARGET=web|desktop`; `GetCapabilities()` скрывает недоступное. ESLint `no-restricted-imports` на биндинги.

## Рассмотренные альтернативы

`if (isDesktop)` по всему коду; две отдельные SPA.

## Последствия

Единая кодовая база UI; фичи включаются по флагам, а не по платформе.
