{{- if gt (int .Values.replicaCount) 1 }}

ВНИМАНИЕ: replicaCount={{ .Values.replicaCount }}. Несколько реплик пока НЕ поддерживаются: веб-сессии, события и
счётчики блокировок входа хранятся в памяти каждого процесса. Пользователь, попавший на другую реплику,
потеряет сессию, а события и потоки (терминал, логи) будут приходить не туда. Поддержка появится вместе
с HA (этап 4 плана). Верните replicaCount=1.
{{- end }}

{{- if .Values.secrets.create }}

ВНИМАНИЕ: secrets.create=true — Secret создан из values (режим для разработки). Ключ шифрования теперь
хранится в истории релиза Helm и, скорее всего, в вашем репозитории или CI-логах. Чарт ключ не генерирует
и не хранит копию вне кластера. Для production создайте Secret отдельно и задайте secrets.existingSecret.
Secret помечен helm.sh/resource-policy: keep и переживёт `helm uninstall`.
{{- end }}

Ключ шифрования ({{ .Values.secrets.keys.secretKey }}) нужен всегда: БЕЗ НЕГО секреты в БД (kubeconfig, токены Argo CD)
прочитать невозможно. Храните копию ключа отдельно от резервных копий БД (docs/deploy.md).
{{- if not .Values.secrets.create }}
Секреты читаются из Secret «{{ .Values.secrets.existingSecret }}»; после смены его содержимого перезапустите Deployment:
  kubectl -n {{ .Release.Namespace }} rollout restart deploy/{{ include "kubron.fullname" . }}
{{- end }}
