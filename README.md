# Kubron

Десктопное приложение для управления Kubernetes (Wails + Go + Vue). Веб-версия и режим
сервиса для команд — в разработке (см. `docs/adr/` и `docs/tickets/`).

## Веб-режим (в разработке, этап 1)

```
cd frontend && npm ci && npm run build && cd ..
go run ./cmd/kubron-server --listen 127.0.0.1:8080
```

Сервер пока работает в режиме одного пользователя и слушает только loopback (`--allow-remote`
небезопасен до появления cookie-сессий). Методы приложения доступны через `POST /api/rpc/{метод}`
(тело — JSON-массив аргументов); перечень разрешённых методов — `internal/server/methods.go`.
Фронтенд для веба (замена Wails-слоя `src/platform/*`) — задача 1.7, поэтому сейчас в браузере
откроется десктопный интерфейс без связи с бэкендом.

## Лицензия

Ядро Kubron — открытый код под лицензией [Apache-2.0](LICENSE).

Планируются платные функции по подписке. Первая из них — **вход через SSO/OIDC** для
организаций: она будет отдельным коммерческим модулем. В открытом ядре всегда остаются
локальные пользователи, роли, журнал аудита и аварийный вход администратора.
